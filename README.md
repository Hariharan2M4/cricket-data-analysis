# 🏏 Best 11 Cricket Team - Power BI Project

This project uses Power BI to analyze cricket player performance and help select the **Best 11 Cricket Players** based on batting, bowling, and all-rounder statistics. It was built as part of the [Codebasics Power BI Challenge](https://www.codebasics.io/).

## 📊 Features

- Interactive dashboards for player stats
- Filters by role (Batsman, Bowler, All-rounder, Wicketkeeper)
- Visual comparison of runs, averages, strike rates, economy, and wickets
- Dynamic Best 11 team selector based on performance metrics

## 📁 File

- `Codebasics Cricket Best 11.pbix` – The Power BI report file

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using **Power BI Desktop**.
3. Explore dashboards, apply filters, and modify visuals as needed.

## 🛠 Tools Used

- Power BI
- DAX
- Power Query Editor
